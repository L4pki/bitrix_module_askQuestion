# Установка и настройка модуля для Bitrix

## Шаги по установке

### 1. Скачайте архив
Скачайте архив с модулем и распакуйте его в папку `local/modules` в корне вашего сайта на Bitrix.

### 2. Установите модуль в админке Bitrix
- Перейдите в административную панель вашего сайта.
- Найдите раздел **"Настройки"** → **"Управление модулями"**.
- В списке модулей найдите ваш модуль и нажмите кнопку **"Установить"**.

### 3. Настройте модуль
- После установки перейдите в настройки вашего модуля.
- Укажите необходимый URL вашего сайта на Bitrix и ключ хука.

### 4. Установите компонент
- Откройте визуальный редактор вашего сайта.
- Найдите и выберите установленный компонент.
- Установите компонент на нужной странице.

### 5. Заполните форму
- После установки компонента, перейдите на страницу с формой.
- Заполните все необходимые поля и отправьте форму.

### 6. Получите лид
После отправки формы, на ваш Bitrix придет оформленный лид с указанием веб-сайта.

## Примечания
- Убедитесь, что у вас есть все необходимые права доступа для установки модулей и настройки компонентов.
